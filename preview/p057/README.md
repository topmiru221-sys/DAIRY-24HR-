# DAIRY 24HR · P0.5.7｜榨乳室＋儲乳區＋牧場管理室

**試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p057/

本版由已可玩且經使用者驗收的 P0.5.6.1 延伸，新增可走動、可互動的兩個室內 3D 區域，**不覆蓋 P0.5.6.1 或任何先前穩定版**。

## 三個可走動的工作區域

| 場景 | 3D 設施 | 玩家互動 |
|---|---|---|
| 🐄 榨乳室 | 10 個牛位、完整早場 9 階段、員工／設備動畫、進出場柵門 | 牛隻、乳杯、管路、清洗控制、工作人員、兩個門口 |
| 🥛 儲乳區 | 水平不鏽鋼保溫儲乳槽、檢修孔、乳管／清洗接口、冷卻機組、溫度面板、清潔槽、出乳口 | 查看儲乳桶、模擬溫度、冷卻設備、衛生台與集乳車接乳口 |
| 🗂 管理室 | 桌機雙螢幕、文件／值班紀錄、工作白板、文件櫃、監控示意屏幕、交班桌、值班表 | 看值班紀錄、交班事項、牧場監控示意與文件 |

### 進出房間與手機操作

- 使用畫面右側 **🐄 榨乳室／🥛 儲乳區／🗂 管理室** 切換區域；新區域有自己的 3D 地板、牆壁、擺設、觀察點。
- 榨乳室工作通道靠入口處另設兩個 **E／互動** 門口，走近可以進入其他區域。
- 進入儲乳區或管理室後，往入口端走到「返回榨乳室」也能按 E 返回。
- 舊版已驗收的 **WASD／方向鍵、手機 D-pad、點地面移動、鏡頭環繞** 公式未修改。切換區域只在切換瞬間把人物移到該房入口，不影響一般走路。
- 榨乳室早場的自動階段在參觀其他房間時仍然推進；回來後會依當前階段更新。
- 所有房間都只有簡短現場互動，不強迫答題。

## 儲乳槽數值與設備說明

顯示屏上的 **3.8°C 為遊戲模擬示例**，不代表即時資料、實測溫度或某牧場當日品質成績。未填入真實奶量、牛隻疾病及正式放行紀錄。模型依使用者提供《東海大學0617》榨乳系統／管路的教學概念延伸，**不是設備廠商施工圖，不提供實際工程尺寸**。

管理室的螢幕、交班白板和 DHI 文件僅是情境擺設，不與任何實際資料庫、個人資料或攝影機連線。

## 已知限制

- 三個區域目前採 **場景切換與入口互動**，不是一張可連續走遍所有建築的開放世界地圖；這是為了保留已經穩定的行走座標範圍與手機效能。
- 儲乳槽、冷卻機組、清洗接口、管理室均屬原創低多邊形示意；尚未建立真實的乳溫控制、感測器讀數、CIP 配方設定和紀錄輸入功能。
- 無牛寶或 DairyLife 360 遊戲內入口，保持 DAIRY 24HR 獨立專案。
- 僅完成程式層級驗證及 GitHub Pages 部署；手機畫面中的遮擋、動畫、幀率與角色穿模仍需使用者實機驗收。

## 版本驗收

1. 榨乳室方向鍵、點地移動及牛隻進出場仍正常，按 🥛 可以進到新儲乳區。
2. 儲乳區能自由走動，槽體、冷卻機與溫度示意牌清晰，E 可查看五種設備。
3. 管理室有電腦、文件櫃、交班桌，走近按 E 可得到簡短自然提示。
4. 按「返回榨乳室」或右側標籤返回後，鏡頭、按鍵不應失效，也不能出現 NaN／人物亂跑。
5. 回到榨乳室後，牛隻與完整早場階段應繼續正常演出。
