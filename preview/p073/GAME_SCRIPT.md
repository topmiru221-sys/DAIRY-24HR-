# DAIRY 24HR｜現有遊戲劇本索引

這份索引把目前已實作的劇情分成「完整日間主劇本」與「新版 3D 場景內的早班支線」，方便後續繼續寫 24 小時內容。

## 1. 完整日間主劇本（04:00–18:30）

- 位置：專案根目錄 `index.html` 的 `missions`。
- 內容：共 8 個日常工作站，從 04:00 上班與交班本開始，經過榨乳、儲乳、Fresh 牛、飼料與環控巡視，18:10 回辦公室交班，18:30 收工。
- 特點：每站有現場觀察、自然對話、隨機情境、玩家筆記與日終評語；不是固定答題闖關。

## 2. P0.7.3 場景內早班支線（05:10 起）

- 劇本資料：`shift-story.mjs`
- 接線與對話顯示：`scene.js`
- 四項可選任務：查看榨乳用品、查看儲乳溫控示意、查閱早班紀錄、回榨乳室向美玲姐回報。
- 三種開始方向：先看牛位、先看儲乳、先看紀錄。
- 三組隨機環境台詞，讓重玩時不會完全相同。

## 3. 榨乳流程演出

- 流程資料：`cycle.mjs`
- 畫面與設備動畫：`scene.js`、`working-parlor.mjs`
- 目前是可暫停、跳段、重播的早場流程演出，和早班支線並行。

## 4. 場景進度定位

- 泌乳牛舍：大致完成，後續以回歸保護與小幅精修為主，不改動已驗收的平板風扇樣式。
- 乾乳牛舍／Close-up 待產舍：沿用 P0.7.1 已完成的屋頂送風、設備避讓與牛位穿模精修。
- 牧場總圖：P0.7.2 改為前端榨乳作業群、主牛舍連續分區、育成／犢牛側與後勤服務線。
- 主牛舍動線：P0.7.3 可從泌乳區直接步行到乾乳與 Close-up 待產區，後續劇情可在同一空間連續觸發。
- 24 小時劇本：目前尚未完整串接夜班；下一階段可把乾乳巡欄、Close-up 夜間巡視與交班接入主時間軸。

以上內容均為遊戲敘事與場景示意，不是畜牧、醫療或通風工程指引。
