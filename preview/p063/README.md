# DAIRY 24HR｜P0.6.3 牛群加倍、平板扇、牛舍／運動場雙扇活動門

🎮 **試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p063/?v=p063

本版是使用者驗收 P0.6.2 後的新要求：**牛隻數目加倍、新增大型平板扇，並且把牛舍與戶外運動場區隔得更清楚，新增真正能控制通行的活動門。** 本版只改泌乳牛舍，其他十個設施、三間精修室內，以及既有牧場道路／地圖骨架不變。

### 大型平板扇

既有屋架上水平面風扇不刪除，另外在左右側柱各掛 **三組（手機）／四組（桌機）的大型薄型方框式軸流平板扇**。模型有方形金屬護罩、內側護網、圓形大扇葉及側向支架，朝牛位並向下傾斜；動畫扇葉獨立旋轉。這與原本天花板上方的風扇是**不同設備模型**，不是複製屋頂風扇的造型。

### 雙扇活動門

牛舍與運動場的交界設：
- **清楚可辨的黃色地面分界**，與左右連續金屬圍欄。
- **中央寬的雙扇鉸鏈式活動門**，兩片門扇能旋開進入戶外。
- **兩種方式操作**：靠近中間的活動門按 E／觸控互動，或在泌乳牛舍右側 HUD 點「🚪 關閉活動門／打開活動門」。
- **門的狀態會實際控制玩家通行**：關閉時不允許穿越交界，開啟時允許由中央門口往返。兩側圍欄即使開門也不能穿越。
- 牛舍／運動場的「快速預覽」快捷鍵會遵守關門狀態，不能繞過已關閉的門。
- 預設為開門，方便玩家進場後一路走到牛舍；可以自行關閉驗收。

這是遊戲動線和門扇動畫，不是實際控制任何牧場的機械門。現有牛群動畫仍各自保持在室內或戶外，尚未實現會主動走過門的乳牛進出欄完整系統。

## 優先實機驗收

1. 選泌乳牛舍：手機至少能辨識 24 頭，桌機版 32 頭，牛不應擠在單一牛床。
2. 屋架風扇依舊存在；抬頭／拉遠看兩側立柱可辨認大型方形平板扇與防護框。
3. 靠近 **牛舍／戶外運動場交界**：有完整圍欄、黃線與雙扇活動門。
4. 點右側「🚪 關閉活動門」，門片慢慢關閉；再試著從中央通道走，應被阻止。
5. 點「🚪 打開活動門」，門片往戶外旋開；沿中央通道再走，應可穿越。
6. 關門時按「牛舍／運動場」快捷切換，應出現提示而非瞬間穿越。
7. 返回榨乳室／儲乳區／管理室，確認原本的流暢移動和作業動畫仍正常。
