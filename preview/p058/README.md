# DAIRY 24HR｜P0.5.8 三區域早班故事

**獨立試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p058/

## 從場景展示走向可玩的早班故事

本版直接沿用 P0.5.7 的榨乳室／儲乳區／牧場管理室，新增**可自由選擇順序、完全自願完成**的早班工作；不要求玩家辨認任何疾病或必須答對問題，故事也不會阻擋原有榨乳動畫。

### 四項工作

| 工作 | 區域 | 真正要接近的遊戲物件 |
|---|---|---|
| 查看榨乳用品 | 榨乳室 | 前處理用品架（E 鍵互動） |
| 留意儲乳設備 | 儲乳區 | 示意溫度面板（E 鍵互動） |
| 查閱當班紀錄 | 管理室 | 管理電腦桌（E 鍵互動） |
| 向美玲姐交班 | 返回榨乳室 | 美玲姐（前三項完成後的自然對話） |

玩家先與美玲姐互動並不會被鎖在任務上：普通聊天始終可用。前三項任務不必按照固定順序，重複互動不會重複計數；交班後仍可任意探索三個空間。

### 玩家選擇與後果

- 可在「📋 早班任務」面板選擇工作優先方向：**先看牛位／先看儲乳／先看紀錄**。
- 選擇影響交班時美玲姐的回應，並且不是對錯測驗。
- 進入新場景可看到一次性的簡短旁白；停留片刻會隨機出現**平常牧場日常**的小事件，包括同事互動或環境聲音。沒有預設病牛或設備故障。
- 依照互動解鎖進度，工作表顯示勾選、指引位置，以及「📍 前往下一站」便捷切換。
- 遊戲內時間由 **05:10** 開始推進，並明確標示為「遊戲時間（加速）」。這是早班故事的演示時間，不是真實流程的計時或量測結果。
- 面板可收合，不需要一直打開；背景榨乳室的進出場、接杯、脫杯和清洗動畫繼續獨立運行。

### 手機優先驗收

1. P0.5.3 原本的移動、拖曳鏡頭、方向鍵、點地面行走與互動按鈕完全保留；沒有修改 `playerMove(dt)`、`controls.mjs` 與事件處理。
2. 在榨乳室入口按右側「📋 早班任務」，確認清單不會永久遮住畫面；按 ✕ 可以收起。
3. 選擇任何工作方向，前往目標場景並用 E 或右下角互動完成任務。
4. 查看儲乳區溫度仍清楚寫著「模擬」，管理室內容並未接上任何真實紀錄。
5. 完成任意三項後回榨乳室找美玲姐，可看到依工作方向不同的自然對話。
6. 完成後不鎖住任何遊戲操作；仍能查看九段榨乳作業動畫。

## 清楚的開發界線

這一版是 **24 小時遊戲中「早班工作章節」的可玩技術切片**，還不是完整一天 24 小時的正式劇情。新增任務屬場景探索與故事回饋，並不執行真實設備控制、即時乳溫或酪農檢測。沒有牛寶或 DairyLife 360 遊戲內求助入口。

本版不覆蓋正式 P0.4，也不更動已驗收的 P0.5.3 控制基底。舊版 https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p057/ 仍可直接開啟比較。

目前完成代碼與純邏輯測試，但**手機上的遮擋、幀率、穿模及 E 鍵可用性仍要實機驗收**。
