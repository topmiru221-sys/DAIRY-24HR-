# DAIRY 24HR｜P0.6.5 遊戲畫面資訊／場景選單收合版

**可玩網址**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p065/?v=p065

## 這次只改 UI，不動前版的遊戲內容

使用者在手機試玩 P0.6.4 時指出：**左側區域資訊／探索面板**與**右側場景切換選單**佔用大量畫面，遮住牛隻與設備。依要求將兩組大型控制面板改成預設收合、需要時再開啟。

### 改動與使用

- **左側「ℹ️ 資訊」**：預設只顯示小按鈕，點擊展開區域說明、探索計數、原有榨乳流程按鈕及泌乳牛舍／運動場快捷鍵與活動門開關。再次按「✕ 收起資訊」即可隱藏。
- **右側「🧭 場景」**：預設只顯示小按鈕，需要看「全區地圖」「牧場總覽」「榨乳室」「儲乳區」「管理室」及早班任務入口時點擊展開。再次點選收合。
- **不互相遮蓋**：打開左側資訊時自動收起右側場景，反之亦然。
- **自動收起**：選擇場景、開啟全區地圖或打開早班任務時，兩側資訊控制自動收合，回復完整 3D 遊戲畫面。
- **手機優先**：收合按鈕體積小，放在原有面板頂端，完整資訊面板仍可捲動。保留原本的鏡頭操作、手機方向鍵和右下角靠近互動。
- **預設行為**：每次重新開啟遊戲都先收合兩組資訊。無須另行儲存、登入或清除快取。

### 嚴格不變

P0.6.4 的 24/32 頭乳牛、自由牛床及運動場、兩類沿走道排列的風扇、頭鎖噴淋、刮糞、牛背號碼、頸圈感測器、室內外雙扇活動門及通行限制、另外十個區域、已精修的榨乳室／儲乳區／管理室，全部保持原狀。

實作僅調整 `index.html` 的 UI 排版與 `scene.js` 的資訊面板開合事件，其餘所有遊戲模組直接複製自 P0.6.4。原來的 P0.6.4 保留不變。

## 驗收重點

1. 在 Android 手機開啟 P0.6.5、開始遊戲後，左右大面板**預設不顯示**，應能清楚看見牛群。
2. 點「ℹ️ 資訊」展開左側面板，再點收起；同理測試「🧭 場景」右側選單。
3. 同時嘗試左右切換，應自動關閉另一側，避免佔滿畫面。
4. 用右側場景按鈕跳轉牧場、榨乳室，面板應自動收合。
5. 在泌乳牛舍打開資訊，測試「牛舍／運動場」快捷按鈕和活動門開關；收合之後既有設定仍應保持。
6. 驗收手機方向鍵、鏡頭旋轉、全區地圖與 E／靠近再互動等功能。
