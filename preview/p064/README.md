# P0.6.4｜風扇方向與位置校正

**試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p064/?v=p064

這版僅針對**泌乳牛舍的兩種風扇**修改空間位置、安裝面與扇葉旋轉軸，其他三個精修區域、全牧場 16 地圖節點、14 建築入口、戶外運動場、活動雙扇門、牛背編號、感測頸圈、降溫噴嘴和刮糞機均保持原本功能。

## 修正內容

| 設備 | P0.6.3 問題 | P0.6.4 改動 |
|---|---|---|
| 屋架懸吊式圓形風扇 | 平放朝下吹，與平板風扇互相垂直 | 改成**垂直扇面**、由屋架懸吊，軸向沿牛舍長軸／走道送風 |
| 大型方形平板扇 | 裝在左右牆柱、朝橫向吹牛群 | 改成**沿縱向走道上方懸吊**，扇面與圓形風扇平行，送風方向同樣沿走道 |
| 風扇排列 | 交叉安裝，有視覺上互相干擾 | 分列於不同牛隻走道上方，並調整前後間距；避免實體扇框互相交疊 |
| 扇葉轉動 | 圓形扇葉繞垂直 Y 軸轉動 | 兩種扇葉統一繞縱向 Z 軸轉動，與送風軸一致 |

**坐標與方向**：遊戲內牛舍長向走道沿 Z 軸；牛隻在牛床或採食頭鎖前的身體大致沿 X 軸。因此兩種風扇的扇面均在 X-Y 平面、送風軸為 +Z，送風與走道平行、與牛身方向垂直。這是本遊戲的配置約定，並非適用於每一種現實牛舍的唯一安裝標準。

手機保留 12 組屋架懸吊風扇、6 組大型平板扇；桌機保留 18 ＋ 8 組。牛數仍手機 **24 頭**、桌機 **32 頭**。

## 驗收重點

1. 進入泌乳牛舍，觀察原本的圓形懸吊風扇與方形平板扇是否都**沿牛舍長向送風**，不再是一組朝下、另一組橫吹。
2. 風扇的扇面應保持互相平行，不垂直，也不互相穿模。
3. **兩種風扇並非同一列重疊**：圓形扇在不同牛床／採食區上方，平板扇沿刮糞及牛隻活動走道分開吊掛。
4. 驗收手機 24 頭乳牛、戶外活動門開關、牛背號碼、噴淋／刮糞互動是否保持正常。

## 檢查

- 3D 模型程式已通過語法與 Three.js mock 幾何建立。
- 針對手機、桌機的所有風扇位置，新增 `fanLayout` 資料供測試：`axis=[0,0,1]`、`face='XY'`，且兩兩扇體的簡化碰撞球不重疊。
- `lactating-barn.test.mjs` 包含上述方向、位置、數量及原本動物／活動門功能回歸。
