# DAIRY 24HR｜P0.5.4 榨乳室 1242 號牛位精修

🎮 試玩：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p054/

## 與 P0.5.3 差異

本版只精修 **1242 號牛（左側第二牛位）**，其他牛位仍是前版外觀，方便直接比較。仍在製作美術與互動原型，並非工程級設備尺寸模型。

- 新增與乳房位置對齊的 **四個乳杯、四組乳嘴內襯外觀、短乳管、中央集乳座（claw）**。
- 乳管與脈動管用不同材質區分，曲線管路連到固定牛位設備，避免之前的「乳杯懸在工作坑裡」。
- 新增 **脈動器、圓形真空表、乳流顯示區**（示意，無捏造數字）、固定架、藥浴瓶、紙巾與清潔用品架。
- 1242 號牛的乳房局部外觀、黑白斑紋及牛位標示有更多細節。
- 美玲姐靠近示範區，加入伸手、收手和簡單站姿變化，對話縮成牧場日常口吻。
- **P0.5.3 控制器與主角色連續移動邏輯保持原樣**，不把任何教學內容改成強制對答。

## 參考資料

依使用者提供《東海大學0617.pptx》：第 20–21 頁擠乳準備與流程、第 32–35 頁基本設備及管路、第 41–44 頁軟管與脈動器、第 50 頁集乳座與乳杯、第 62–64 頁流量計及 CIP。完整規格：[`../p05/MILKING_ROOM_REFERENCE_P054.md`](../p05/MILKING_ROOM_REFERENCE_P054.md)。

### 建議驗收

1. 點擊走動和手機方向鍵依然絲滑、沒有回起點或跳出異常。
2. 走到**左側第二牛位 1242**，左右旋轉看四個乳杯是否靠近乳房，集乳座及乳管沒有飄在半空中。
3. 比較其他未精修牛位，觀察牛隻外觀、管線和儀表的辨識度是否有明顯提升。
4. 美玲姐會做簡單工作手勢、靠近可聊天，但不強迫逐點確認。

### 已知限制

P0.5.4 還不是完整榨乳操作遊戲：乳杯目前為**已接杯的展示模型**，尚無完整「前處理 → 接乳杯 → 乳流變化 → 脫杯」動畫；也尚未逐牛位替換其他九組設備。日間 24 小時故事仍保留在主線專案，沒有把牛寶或 DairyLife 360 放進遊戲。

使用者端手機 GPU 表現及視覺效果需實機驗收；正式主頁和 P0.5.3 均未改動。
