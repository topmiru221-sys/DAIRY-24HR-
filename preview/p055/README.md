# DAIRY 24HR｜P0.5.5 運作中的榨乳室

**獨立試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p055/

## 本版完成內容

- **10 個牛位採用一致的精修設備**：每頭牛都有乳房、四乳頭、四個乳杯、中央集乳座、短乳管、長乳管與脈動管。乳杯與管路跟著牛位，不再是原版工作坑中懸空的四個柱體。
- **十組操作面板**：小型脈動器、乳流示意燈號、管線支架與代表性真空表；面板上的變化是**動畫示意**，沒有編造真實臨床數據。
- **不同牛位的正常工作階段**：準備中／榨乳中／完成，每個牛位不同步。動畫時間為遊戲展示而縮短，**不是真實擠乳所需時間**。
- **乳牛的低幅度動作**：身體呼吸起伏、頭部輕微擺動、四肢重心轉移，原有甩尾保留。
- **員工不再固定不動**：美玲姐會伸手做事、換站姿，阿力會在另一側短距離走動。
- **自由觀察十個牛位**：走近即可聊天或查看作業階段，不必逐頭完成對話或先選一個「正確原因」。
- **可自行開啟的輕量環境音**：右上角 🔇；以 Web Audio 即時合成低音量機械嗡鳴，預設靜音、無外部音檔。
- **保留 P0.5.3 的流暢操作**：`controls.mjs` 與 `playerMove(dt)` 控制程式完整沿用，點擊地面與手機長按方向鍵均不改動。

## 參考資料與界線

依使用者提供的《東海大學0617》簡報參考第 20–21、32–35、41–44、50、62–64 頁的器材、流程及設備連接。遊戲中的牛位模型屬於**自製低多邊形情境示意**，並無真實牧場的尺寸、廠牌系統或配管施工圖。模擬不等於現場 SOP，所有指標、流程及動畫不能作為診療、乳品放行或設備維修依據。

本版保留既有設計原則：沒有牛寶／DairyLife 360 遊戲內整合；不預設一定有乳房炎、細菌或設備故障，正常的一天也能自由探索。

## 測試與驗收

程式回歸測試：
```bash
node preview/p055/controls.test.mjs
node preview/p055/working-parlor.test.mjs
```

手機實機請觀察：長按方向鍵和點擊移動是否仍絲滑；旋轉鏡頭時每頭牛的四乳杯是否附著正確；美玲姐與阿力是否自然活動；動畫有無穿模、閃爍或掉幀；音效按鈕能否由玩家主動關閉。

## 已知限制

- 乳杯接合／脫杯目前是簡化的場景狀態切換，不是完整逐步套杯或自動脫杯的精準操作動畫。
- 尚未製作牛隻自主進出場、正確完整前處理、真實乳流曲線或收工 CIP 操作。
- 目前只是一個早班榨乳室 3D 技術切片，完整 24 小時事件與劇本並未放入這個測試版本。
- 行動裝置畫質與效能需實機驗證，不能僅憑程式測試聲稱已無卡頓。
