# DAIRY 24HR｜P0.5.9 全牧場地圖骨架版

🎮 **遊玩預覽**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p059/

> **本版開發策略：先固定整張牧場地圖與所有建築，再回頭逐區補任務、牛隻、設備及故事。** 不將「骨架完成」等同於「內容完成」，不覆蓋任何舊版。

## 已實作範圍

- **一張可走動的整座牧場 3D 總圖**：主車道、橫向連接道路、場界圍欄、出入口、植栽、集乳車入口、16 個有固定定位的功能／交通節點。
- **14 棟具備獨立進出點的工作建築**，沒有兩個入口占用同一座標。每個入口在 3D 世界可靠近按 E，亦可用右側「🗺 全區地圖」直接選取。
- **3 個已完成內容的區域保持原版**：榨乳室（含牛隻、乳杯與早班流程）、儲乳區、牧場管理室。
- **11 個新增的可進入空間骨架**：可走動地板、中央走道、開放式廳舍框架、標示牌、基礎分區設備、返回中庭入口。**沒有謊稱已完成各區詳細互動與動物模型。**
- 2D 場地地圖及設施名錄從 `farm-masterplan.mjs` 同一份 `ZONES` 資料動態產生；3D 入口也由該份資料建立，未來變動不用重新維護兩套地圖。
- **手機操作延續原本的方向鍵、點擊移動及鏡頭控制**；只有地圖總覽在 x、z 方向的行走範圍擴展到整座牧場。舊室內沿用原本的碰撞邊界與方向鍵數學。
- 地圖總覽時先隱藏早班任務面板和榨乳階段按鈕，避免跟主要驗收目標混淆；進回精修場景後恢復。

## 地圖如何驗收

1. 一進遊戲便從牧場正門附近開始，往內沿中央道路走動。
2. 按右側「🗺 全區地圖」，確認每個設施都有對應 2D 點位與名錄。
3. 從地圖直接開啟 **犢牛舍**、**待產／Close-up**、**Fresh**、**飼料中心**、**糞污處理**、**農機區**等空間；每區都能自由行走，標示名稱正確。
4. 在區域內靠近入口端按 E「返回牧場總覽」，回中央道路；也可直接用右側按鈕。
5. 在牧場總圖沿道路走到建築入口牌，按 E 進入；所有 14 處入口座標唯一且在可走動範圍。
6. 進入 P0.5.8 已有的榨乳室、儲乳區、管理室，確認原本操作、牛隻步態、溫度模擬與任務沒有被破壞。
7. 手機觀察效能、按鍵遮擋與各建築標示；任何地圖尺寸與動線問題，先改地圖結構，不做新的內容分支。

## 技術結構

- `farm-masterplan.mjs`：`ZONES` 資料、`AREA_IDS`、地圖道路、室外建築輪廓、每個場域的門口、11 棟獨立低模室內骨架。
- `scene.js`：複用原版 Three.js 的渲染、相機和輸入，將地圖接到 `setArea()`／`stations`／地圖 UI；戶外可走動範圍依場景調整，方向鍵運動邏輯仍為 P0.5.3 基礎。
- `index.html`：有折疊式全區地圖與兩欄設施清單；舊版早班面板保留。
- `controls.mjs`：與前版完全相同。
- `farm-masterplan.test.mjs`：檢查 16 節點、14 唯一入口、11 骨架、有效區域 ID 與區域顯示切換。
- 其餘原有 `working-parlor`、`cow-walk`、`cycle`、`shift-story`、`support-rooms` 模組均由 P0.5.8 直接保留。

## 重要限制

- **地圖骨架版，不是全牧場內容完整版**。新增 11 區的設備是占位示意，尚未實作動物日常、繁殖管理、TMR 配方、治療、生物安全流程或細節動畫。
- 尚未完成開放世界式的連續跨建築室內步行；入口採實體 E 互動／地圖選擇切換，以確保手機效能和易驗收性。
- 模型為原創低多邊形牧場平面規劃示意，不是特定真實牧場尺寸或建築施工圖。
- 不加入牛寶與 DairyLife 360 遊戲內入口。
- 自動測試與 Pages 部署可查；手機 WebGL 畫面、幀率與遮擋仍須實機確認。
