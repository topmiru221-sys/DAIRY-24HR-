# DAIRY 24HR｜P0.6.1 真實牧場設施重建版

▶ **試玩**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p061/?v=p061

## 更新原則

本版依使用者驗收：**P0.6.0 十一個未精修區域的內部配置與真實酪農場差異太大**。因此不是換幾種貼圖，而是刪除十一區原有的共通複製式房間物件，將各空間依真實設計原理與工作動線重新建模。參考資料與模型理由見 [REAL_FARM_REFERENCES.md](REAL_FARM_REFERENCES.md)。

**嚴格保留**：已驗收的榨乳室、儲乳區及管理室三大精修場景、十頭乳牛運作、P0.5.3 手機滑順移動、P0.5.6.1 乳牛正面行走、早班任務與全牧場道路／16 地圖節點／14 個入口。正式版根目錄 `index.html` 不更動；獨立版本置於 `preview/p061/`。

### 關鍵交互與效能

- 十一區均有**三個依現場設施定位的 E／手機互動物件，共 33 處**。
- 牛隻可微微擺頭甩尾，部分設備有慢速工作動畫。
- 手機只保留精簡牛隻模型數量；場景隱藏時不執行其動作更新。
- 所有十一個場景使用各自的場域專屬函式和結構，**不再複製同一間房、同一列三個櫃子**。
- 2D 全區地圖可以直接進入各區，也可以從戶外道路靠近入口按 E。

### 開發與驗收限制

**這是研究參考的可信牧場空間「視覺原型」，不是 1:1 實體建築圖。** 遊戲仍沿用原本每棟建築的小尺寸空間和手機自由走動限制，因此沒有將來源文獻中所有英呎、公尺的工程尺寸硬塞進模型。實際牧場應由酪農場、獸醫、設施設計／建築人員配合牛群規模、氣候、畜舍形式、安全與法規另行設計。

資料來源主要是 Wisconsin Dairyland Initiative、UW Extension、Penn State Extension、NC State Extension 及 Dairy Conservation Navigator。原始圖片僅用來判讀形態，不複製進遊戲成為第三方貼圖。

### 實機請優先檢視的五區

1. **泌乳牛舍**：牛床隔欄、採食頭鎖、餵飼通道是否有真實牛舍感。
2. **犢牛舍**：獨立欄、側隔板、奶桶與服務走道是否合理。
3. **Close-up 與 Fresh**：是否能看出不同的群欄與用途。
4. **TMR 與青貯區**：堆料方式與車輛動線是否更符合日常作業。
5. **糞污處理區**：分離設備與圍欄處理池不應再像普通牛舍。

如果大型模型的尺寸、方向、室內視角不合理，以實機畫面再精修；**GitHub Pages 正常部署≠ Android 實機畫面驗收通過**。
