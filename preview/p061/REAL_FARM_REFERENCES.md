# DAIRY 24HR P0.6.1｜真實牧場設施設計參考與改建紀錄

**用途**：十一個原先過度簡化的遊戲場域，依有公信力的酪農／農業設施參考重建。**這份資料只佐證「空間原理與設備關係」**，不代表目前 3D 模型已達施工圖等級，更不能直接用於建築施工、乳牛福利稽核或現場標準作業程序。

## 臺灣牧場在地環境參考｜開放式牛舍、降溫和高濕度

- **農業部農業科技專案計畫服務網：乳牛畜舍環境改善與智慧化監控管理**  
  https://agtech.moa.gov.tw/news/news_more?id=36db3b5ed1674c6e84a4a72b40fcebb4  
  指出高溫熱緊迫下，牛舍常透過通風風扇、噴水／噴霧及遮蔭調節環境；各設備要與管理和感測搭配。
- **農業部畜產試驗所：水簾牛舍熱緊迫可行性評估 I**  
  https://www.tlri.gov.tw/view.php?id=1408&subtheme=&theme=personal_work  
  臺灣高濕條件下，單靠增加濕度不保證牛體降溫，必須留意通風風速、濕度和牛隻生理反應。
- **農業部畜產試驗所：水簾牛舍熱緊迫可行性評估 II**  
  https://www.tlri.gov.tw/view.php?id=1001&print=Y&subtheme=&theme=personal_work  
  不同通風與水簾設計對採食、泌乳表現的效果不一定相同，不能把水簾／噴霧直接宣稱為最佳方案。
- **台南柳營桂芳牧場的開放式牛舍實景報導**  
  https://smiletaiwan.cw.com.tw/article/9072  
  可觀察開放側牆、成排牛床、走道、吊掛式大型風扇和高屋架的臺灣牧場外觀。僅供觀察造型，不引用照片入遊戲。

**本版在地調整**：將主要成牛舍設成開放式高屋架、採食／牛床上方掛設風扇，部分區域有**尚未啟動的降溫噴淋預留管線**。場景沒有宣稱水霧持續使用或降低多少溫度；溼度、風速及降溫策略仍是後續獨立驗收項目。

## 1. 牛舍規劃｜自由牛床、飼槽、採食與飲水

- **UW–Madison Dairyland Initiative：Stall Layout**  
  https://thedairylandinitiative.vetmed.wisc.edu/adult-cow-housing/stall-layout/  
  重點：現代自由牛床的行列、採食前緣與牛床行列的相對關係。兩排牛位配置、牛隻採食空間、通風考量和動線，不能以空地上放幾頭牛代替。
- **UW–Madison Extension：Hoof Health & Housing**  
  https://dairy.extension.wisc.edu/articles/hoof-health-housing/  
  重點：牛床隔欄、舒適臥床面、前衝起身空間、溝槽地坪、走道及通風對牛隻舒適的意義。
- **Penn State Extension：Designing and Building Dairy Cattle Freestalls**  
  https://extension.psu.edu/designing-and-building-dairy-cattle-freestalls  
  重點：牛床應能支援自然站起、躺下，依牛型與體型做設計。

**本版實際改建**：泌乳牛舍重新配置兩側成列牛床及迴圈隔欄、中央飼餵通道、頭鎖採食前緣、靠近通道的飲水槽、帶屋架與風扇的開放式牛舍。牛不是排排站在一個方塊上。

## 2. 乾乳、待產 Close-up、產後 Fresh 分開規劃

- **Penn State Extension：Pre-Fresh, Maternity and Post-Fresh Space: Getting the Numbers Right**  
  https://extension.psu.edu/pre-fresh-maternity-and-post-fresh-space-getting-the-numbers-right  
  重點：far-off dry、close-up、maternity、post-fresh 需要不同分群和休息區；低壓力、舒適乾爽的床面、充分採食與飲水優先。
- **Penn State Extension：Do Cows Prefer Privacy During Calving?**  
  https://extension.psu.edu/do-cows-prefer-privacy-during-calving  
  重點：分娩區應給母牛合適的獨立性及空間，避免與一般群欄混淆。
- **Penn State Extension：Restraint and Treatment Facilities for Dairy Animals**  
  https://extension.psu.edu/restraint-and-treatment-facilities-for-dairy-animals  
  重點：分娩、觀察、處置、保定的牛欄與安全門道應清楚設計。

**本版實際改建**：乾乳牛舍為較大的分群深墊料區；Close-up 另設預產群及可區隔產房；Fresh 採獨立產後觀察群與休息區。三區各自有進出門、飼槽、水槽，並非同一張地圖貼不同標牌。無預設病牛或難產。

## 3. 犢牛舍、育成牛舍

- **UW–Madison Extension：Renovating Tie-Stall Barns for Indoor Calf Housing**  
  https://dairy.extension.wisc.edu/articles/renovating-tie-stall-barns-for-indoor-calf-housing/  
  重點：犢牛獨立欄需要適當的隔板、乾燥墊料、通風、清潔服務動線，並因應空氣品質管理。
- **UW–Madison Extension：Air Quality in Calf Housing**  
  https://dairy.extension.wisc.edu/articles/air-quality-in-calf-housing/  
  重點：犢牛欄不同於成牛床；開放／個別或群養、換氣和乾燥墊料都很重要。
- **Penn State Extension：Recommendations for Calf and Heifer Housing Dimensions for Holsteins（2026）**  
  https://extension.psu.edu/recommendations-for-calf-and-heifer-housing-dimensions-for-holsteins  
  重點：不同年齡與體型的犢牛／育成牛，欄位、採食位置和作業需求不可一概而論。
- **Penn State Extension：Precision Feeding Dairy Heifers**  
  https://extension.psu.edu/precision-feeding-dairy-heifers-strategies-and-recommendations  
  重點：育成牛依年齡與體型分群，預留牛隻足夠的採食位置。

**本版實際改建**：犢牛舍設左右兩排真正的個別欄、實心側面隔板、欄前奶桶／水桶、中央服務走道及天花新風管。育成牛舍改為不同尺寸的分齡大群欄，與個別犢牛欄在視覺與空間組成上明顯區隔。

## 4. 飼料中心、青貯及乾草儲區

- **Dairy Conservation Navigator：Feed Center**  
  https://www.dairyconservation.org/practices/feed-center  
  重點：原料分格、遮蔽儲存、裝料和飼料車作業空間必須配置。
- **Dairyland Initiative：Feed Center Design（導覽入口）**  
  https://thedairylandinitiative.vetmed.wisc.edu/  
  重點：飼料配製空間與原料倉不等於數個圓筒料倉置於一間房。

**本版實際改建**：TMR 中心分為混凝土分格原料儲存、車輛走道、移動式攪拌車、秤重控制台。青貯區使用長條式擋牆青貯窖、覆蓋布和配重輪胎，另設乾草捆與鏟裝設備；青貯窖不再是普通室內小方盒。

## 5. 隔離、獸醫處置、糞污、農機

- **Penn State Extension：Restraint and Treatment Facilities for Dairy Animals**  
  https://extension.psu.edu/restraint-and-treatment-facilities-for-dairy-animals  
  重點：獨立牛欄、保定通道、可安全操作的門閘和工作區。
- **Penn State Extension：Manure Separation Facilities**  
  https://extension.psu.edu/manure-separation-facilities  
  重點：固液分離與輸送的配置，依處理型態與處理量而有不同設備選擇。
- **Penn State Extension：Liquid Waste Storage Facilities**  
  https://extension.psu.edu/liquid-waste-storage-facilities  
  重點：貯存構造需因地制宜，並區分地上／地下池、覆蓋／非覆蓋系統。
- **Penn State Extension：Confined Space Manure Storage Hazards**  
  https://extension.psu.edu/confined-space-manure-storage-hazards  
  重點：糞污設施的坑池與受限空間存在高度作業危害；模型設防護欄且不讓玩家操作設備。
- **NC State Extension：Farm Layout and Infrastructure**  
  https://farmplanning.ces.ncsu.edu/land-and-water/farm-layout-and-infrastructure/  
  重點：農機維修工位、工具、零件儲存及作業安全與動線。

**本版實際改建**：獸醫區有獨立牛欄、保定通道、手洗與紀錄桌；糞污區從普通牛舍改成無屋頂工業工作台、固液分離機、圍欄處理池和輸送泵浦；農機區有曳引機停放工位、工具架、保養工作桌及車道。

## 6. 維持的三個原有精修區與地圖

**完全不變**：`parlor` 榨乳室、`tank` 儲乳區、`office` 管理室；16 個地圖節點、14 棟設施入口、戶外道路、原始手機方向鍵和已驗收的牛隻行走。以上模型採原版本檔案複製，未因十一區改建而重做。

## 7. 設計和工程邊界

- **非等比例模型。** 原有 3D 室內場景為固定遊戲長寬，不能直接把本版幾何間距視為公尺、英呎或符合動物福利標準的實際牛床尺寸。
- **不採單一氣候或牧場規格為強制標準。** 台灣高溫高濕條件仍需在下一輪決定通風、降溫、設施材質與地坪排水表現，這次優先定正確的設施形式與設備相對位置。
- **不生成臨床數據、治療處方、TMR 原料公斤數、糞污設施設計容量或任何可用於現場工程施工的參數。**
- **照片與文獻只用於內部判讀及原創低多邊形建模**，遊戲不內嵌原始照片或複製第三方原始模型資產。
