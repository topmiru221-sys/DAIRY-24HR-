# DAIRY 24HR · P0.5.2 榨乳室 3D 重建／手機方向鍵修正

**獨立試玩網址**：https://topmiru221-sys.github.io/DAIRY-24HR-/preview/p05/

這是從 P0.4 抽出的 **Three.js 新引擎驗收場景**，不取代正式首頁；目標是先驗證高辨識度荷斯登牛、角色、榨乳設備，以及手機／桌機的移動鏡頭。



## P0.5.2｜方向鍵回起點修正
- 統一手動方向鍵與點擊地面時的鏡頭目標，移除會造成鏡頭與角色脫節的固定邊界鎖定。
- 發生非法位置值時，回復到**最後一個有效位置**，不再直接把玩家送回起始位置。
- 右上角新增 **🔎** 按鈕，顯示角色 X/Z、鏡頭 X/Z、最近的操作來源及方向鍵狀態，方便辨認是人物跳位或攝影機偏移。
- P0.5.2 沿用原本獨立測試網址，可保留 P0.4 主遊戲不變。
- 這是針對程式中可確認的問題做的修正，實際手機長按方向鍵仍需驗收。

## P0.5.1｜手機方向鍵修正（2026-10-26）
- 修正方向鍵長按時的 pointer 捕捉與狀態釋放，並在切換分頁／畫面失焦時自動清空按鍵狀態。
- 加入鏡頭跟隨範圍保護與 **⌂ 鏡頭回正** 按鈕，可快速恢復起始視角。
- 手機降低渲染像素倍率並關閉即時動態陰影，以減輕部分 Android GPU 負荷；桌機保留陰影。
- 擴充榨乳室外圍地面，避免移至兩端時出現大片空白背景。
- 若 WebGL 繪圖環境遺失，顯示說明而不是完全沒有回饋。
- 保留 `scene-p05-original.js` 作為先前 P0.5 版本備份。
- 這是針對使用者回報的疑似原因所做的修正；**尚需實際手機驗證**，不代表已精確重現故障。

## 已實作
- 程式建模的 10 頭荷斯登乳牛（兩側各 5 頭）、中央榨乳工作道、榨乳杯、乳爪、軟管、上方管線、分隔柵欄、排水溝、控制面板與工作燈。
- 人物有帽子、臉部、工作服、四肢；行走時肢體擺動。
- Three.js 真正透視 3D、深度緩衝、光照與陰影，避免 P0.3 的多面體排序閃爍。
- WASD／方向鍵**持續移動**，手機方向鍵長按，鏡頭跟隨、滑動或拖曳旋轉、雙指／滾輪縮放。
- 可自由靠近美玲姐、阿力、牛隻、設備顯示器、乳杯組和走道查看；沒有固定的「異常考題」，也不強迫把每個地方全部點完。
- 桌機／手機 UI 分別配置，並使用獨立網址測試。

## 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動 | 按住 WASD／方向鍵 | 按住左下方向鍵 |
| 旋轉鏡頭 | 在場景拖曳、Q／R | 左右滑動場景、右上 ↶ ↷ |
| 縮放 | 滾輪、＋－ | 雙指縮放、右上 ＋－ |
| 互動 | E、右下按鈕 | 靠近後點右下「✦」 |
| 目的地 | 點擊地面 | 點擊地面 |

## 範圍

- **這不是完整榨乳作業 SOP，也不是完整 24 小時遊戲**：工作情境只作簡短示範。下一個階段會依實際驗收逐步補上設備動畫、牛隻步態、真實乳頭前處理與更自然的 NPC 行為。
- 為避免授權爭議，本場景模型、控制與互動均自行撰寫，僅使用開源 Three.js 套件；沒有複製 Fab24hr 的原始碼、貼圖或人物模型。
- Three.js 由已固定版本的公共 CDN 讀取，需要網際網路；部分 WebGL 不支援的裝置可能無法啟動。
- 正式 P0.4 仍在 https://topmiru221-sys.github.io/DAIRY-24HR-/ ，兩版可獨立比較。

## 驗收建議

1. 長按移動和同時轉鏡頭，是否順暢而非跳格。
2. 停下看牛，是否一眼能辨認頭、耳、鼻、黑白花紋、腳及乳房。
3. 乳杯、管線、柵欄及擠乳設備是否清楚；有沒有穿模、閃爍或畫面裁切。
4. 在 Android／Chrome 與電腦上有沒有黑屏、發熱或明顯掉幀。

本遊戲為情境模擬，不得代替乳品品質、設備安全與動物診療的現場規範。
