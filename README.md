# DAIRY 24HR｜牧場菜鳥的崩潰值班日

台灣酪農日常題材的互動式方塊 3D 牧場遊戲。**遊戲獨立部署**，與 DairyLife 360 專案無內嵌或程式相依。

## 🎮 P0.4｜移動與場景品質更新（試玩）

- **移動從格子跳步改成連續浮點座標**：方向鍵或 WASD 按住會持續行走，對角線速度一致，起步與停止加入速度平滑，手機螢幕方向鍵支援長按。
- **新的原生 WebGL 立體渲染**：使用 GPU 深度緩衝處理前後遮蔽，不再以原本 P0.3 的 2D 方塊面排序方式重畫，可減少旋轉時的排序閃爍；無第三方 CDN 依賴。
- **清楚區分牛、人、設備**：荷斯登牛有頭、耳、眼睛、口鼻、乳房、四肢及斑紋；工作人員有帽子、臉、手套／工作服及鞋；TMR 料車、拖拉機、儲乳冷卻槽、擠乳設備、風扇等有辨識度較高的低多邊形結構。
- **鏡頭繼續跟隨角色**，支援完整水平 360° 旋轉以及遠近縮放；不再以一格一格的地板表示走路方式。
- **維持 P0.3 劇情與自然交談**，日間 8 個核心工作站點與開放式觀察；保留隨機情境和日終交班。
- **備援版**：[經典 P0.3](./classic.html)，供不支援 WebGL 的裝置使用。

## 操作

| 裝置 | 按鍵 |
|---|---|
| 桌機 | 按住 WASD／方向鍵連續移動、Q/R 轉向、E 互動 |
| 手機 | 按住左下方向鍵移動、點擊互動鍵、在空白場景滑動旋轉鏡頭 |
| 共通 | 鏡頭 ↶／↷、＋／－ 縮放、帶我過去可自動走到地點 |

新版本使用 `dairy24hr_p04` 瀏覽器本機存檔鍵，不覆蓋 P0.3 進度。

## 目前限制

這是 **P0.4 試玩引擎**，場景仍是以程式方塊建模的低多邊形風格，不是 Fab24hr 的原始素材或精緻資產。場景碰撞與設備動畫仍待完善。使用者端不同手機 GPU 和瀏覽器的實際表現需要持續驗收；若出現 WebGL 無法啟動，請用 [P0.3 相容版](./classic.html) 並回報設備。

遊戲仍屬 **04:00–18:30 的日間切片**，完整 24 小時夜班及更多劇情尚未製作。情境和數據非專業臨床、乳品放行或設備維修指引。
