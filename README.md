# DAIRY 24HR｜現代酪農 24 小時生存模擬器

獨立的像素方塊風格牧場互動遊戲專案。專案以《DAIRY 24HR》遊戲劇本 V3.1 為基底，優先開發遊戲內容、人物、事件與選擇後果。

## 🎮 P0.1 試玩版
- 等角俯視方塊牧場場景與角色移動（桌機／手機）
- 場長、牧場員工與事件 NPC 對話
- 交班、冷卻槽、早場擠乳、Fresh Cow、TMR、熱緊迫、下午擠乳與日終交班八項主要任務
- 隨機支線事件、連鎖後果與結算
- 瀏覽器自動儲存進度

**注意：目前是 04:00–18:30 的日間遊戲切片，尚未完成完整 24 小時或夜班。**

## 開始遊玩
1. 如 GitHub Pages 已啟用：打開 https://topmiru221-sys.github.io/DAIRY-24HR-/ 。
2. 或下載 [index.html](./index.html) 並用瀏覽器開啟。

桌機：WASD／方向鍵移動，E 或空白鍵互動，可點擊地圖／任務標記。手機：使用螢幕方向鍵及互動按鈕。

## 網站部署
在此 repository 的 **Settings → Pages → Build and deployment → Source** 選 **Deploy from a branch**，Branch 設為 **main**，Folder 選 **/(root)**，按 **Save**。稍後可在 Pages 設定頁確認正式的遊戲網址與部署狀態。

## 專案隔離
DAIRY 24HR 與 `dairylife360` 是兩個不同儲存庫。此遊戲不內嵌牛寶或 DairyLife 360；知識網站由玩家在遊戲外自行查閱。
