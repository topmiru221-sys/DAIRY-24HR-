# DAIRY 24HR｜牧場菜鳥的崩潰值班日

台灣酪農日常題材的互動式像素方塊牧場遊戲。**遊戲獨立部署**，與 DairyLife 360 專案無內嵌或程式相依。

## 🎮 P0.3｜跟隨鏡頭與自然對話

- 從固定「全牧場鳥瞰」改為**鏡頭跟著玩家**的局部視野；角色走到哪，鏡頭跟到哪。
- 可用 **滑鼠拖曳／手機左右滑動**旋轉鏡頭，支援完整 360° 水平環繞；右側 ↶、↷ 可分段轉向，＋、－ 可縮放。
- 畫面採 **輕量、可旋轉的立體方塊投影**，並非使用外部 3D 模型引擎的擬真場景。
- 手機 UI 精簡，任務卡固定在左上方；右側不再塞入固定小地圖或全景圖。
- **短句對話、單一小面板**：聊兩句／看現場／翻紀錄／先去忙別的；不用每站連按多層確認、填報告才能前進。
- 原有 8 段日間工作、每局 0–3 個不一定發生的現場異常與隨機順路事件保留。觀察是開放式的，不預設疾病診斷。
- 只有起始說明、可選擠乳互動小遊戲、收工結算仍會打開大對話框。

## 操作

- **電腦**：WASD／方向鍵控制畫面方向移動；E／空白鍵互動；Q/R 旋轉鏡頭；滑鼠拖曳轉向；滑鼠點場景移動。
- **手機**：左下方向鍵與互動鍵；**在場景空白處左右滑動**旋轉視角，點地面移動；右側有 ↶ ↷ ＋ －。
- **目的地**：按「帶我過去」角色會自行前往目前任務地點。
- 進度自動保留於目前裝置的瀏覽器（P0.3 獨立存檔）。

## 範圍和限制

P0.3 是日間試玩版，時間約 04:00–18:30，**未完成完整的 24 小時／夜班故事**。方塊角色和設施仍屬原型美術，不是最終 3D 模型；對話和工作場景可以繼續改。

本遊戲情境與數值僅供遊戲體驗，不可取代現場獸醫診療、設備安全操作與乳品品質放行程序。
