# DAIRY 24HR｜現代酪農 24 小時生存模擬器

以簡約等角像素方塊風格呈現台灣現代牧場生活的互動遊戲。遊戲程式與 DairyLife 360 完全分開。

## 🎮 P0.2｜內容與互動更新

- 調整 NPC 對話：改為自然、隨性的日常牧場交談，取消說教式「標準答案」口吻。
- 原本每關預設異常、明示「正確選項」的流程改成 **自由找線索**：可先找人聊天、看現場、翻紀錄，自行決定先看什麼。
- **每局可能有 0–3 項需要再查的狀況**，也可能很平順；不要預設一定生病、設備壞掉或出現單一原因。
- 玩家可以留自己的自由文字筆記，並選擇繼續觀察或將已看見的資訊交班；「還不知道」不是失敗。
- 保留早場擠乳示範互動、地圖走動、4 個可隨機出現的順路地點與日終小結。
- 8 段日間工作任務仍屬 **P0 試玩切片**，不是完整 24 小時遊戲。

## 操作

- 電腦：方向鍵／WASD 移動，靠近人物或黃色標記後按 E／空白鍵。
- 手機：畫面左下的方向鍵與互動按鈕。
- 可點選「帶我過去」自動走到目前工作地點。
- 本版存檔代號 `dairy24hr_p02`，與 P0.1 分開；首次進入 P0.2 為新的一局。

## 設計原則

這不是「牧場考題」。場景中出現的現象有時正常、有時值得進一步查核，玩家透過交流與觀察形成自己的工作記錄，不把推測當作診斷，也不讓未受訓角色執行高風險醫療或設備維修。未完成問題可由下一班續查。

目前是內容與玩法的原型測試，所有劇情、數據和設備設定均不得作為現場診療、乳品放行或維修指引。
